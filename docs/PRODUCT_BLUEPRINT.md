# NUMU V1 Product Blueprint

## Core principle
NUMU teaches evergreen skills rather than a changing national curriculum. Age influences presentation, not the learner's actual skill level.

## User journey
Splash → Parent/Learner entry → Profile → Age range → Goals → Smart Assessment → Personalized Home → Skill Path → Lesson → Game/Challenge → Result → Progress.

## Core screens
- Splash
- Welcome / Sign in / Guest
- Parent account
- Child profiles
- Age and goals
- Placement assessment
- Home
- Skill map
- Lesson player
- Activity renderer
- Daily challenge
- Result
- NUMU AI Tutor
- Progress
- Rewards
- Parent dashboard
- Subscription
- Settings

## Activity types for V1
- Multiple choice
- Tap answer
- Drag & drop
- Matching
- Arrange
- Memory cards
- Timed challenge

## Learning loop
Learn → Practice → Play → Challenge → Mastery

## Mastery rule
Default unlock target: 80%. Weak subskills trigger adaptive review rather than forcing a full-level restart.
