# NUMU | نُمو

**Learn • Think • Grow**  
**تعلّم • فكّر • تطوّر**

NUMU is an evergreen skill-development platform for children and learners. It is not tied to a school curriculum. Each learner has an independent level in Arabic, English, Math, Logic, and Memory & Focus.

## V1 Scope
- Parent account + child profiles
- Age-based onboarding
- Smart placement assessment
- 5 core skill paths
- 20-level architecture (launch content: Levels 1–5)
- Lesson Player
- Reusable activity/game engine
- XP, stars, streaks, badges
- Adaptive mastery tracking
- NUMU AI Tutor gateway
- Parent progress dashboard
- Free / Plus / Family subscription architecture
- Offline-ready content model

## Repository Layout
- `app/` Flutter mobile app architecture
- `backend/` API, data and AI-gateway contracts
- `admin/` Admin dashboard specification
- `docs/` Product, UX, learning and database blueprints
- `.github/workflows/` CI starter

## Learning Paths
1. Arabic
2. English
3. Math
4. Logic
5. Memory & Focus

Levels are grouped into five stages:
- Sprout: 1–4
- Grow: 5–8
- Explore: 9–12
- Think: 13–16
- Master: 17–20
